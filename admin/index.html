🔐 Configuración del servicio

        

          La API key se configura exclusivamente en el servidor. Por seguridad no se muestra ni se edita desde el navegador.
        

        
FACTURAPP_API_KEY=tu_clave
FACTURAPP_EXPECTED_ARTICLES=10000
FACTURAPP_SYNC_ENABLED=true
FACTURAPP_SYNC_HOUR=4
FACTURAPP_SYNC_RESERVE_CREDITS=5

        

          En Dokploy/Easypanel: backend → Environment, guardar las variables y redeployar. La clave nunca se envía al navegador.
